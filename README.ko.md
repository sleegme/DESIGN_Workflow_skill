열려 있던 작업은 모두 **not planned**로 종료했습니다.

## 기존 프로젝트의 목적

`design-workflow`는 실제 실행 도구가 작업하기 전에 무엇을 유지하고 무엇을 바꿀 수 있는지, 그리고 기존 시각 산출물을 보존·확장·신규 제작·명시적 재설계 중 어느 방향으로 처리할지를 결정하기 위한 portable Agent Skill이었습니다.

주요 아이디어는 다음과 같습니다.

- preserve / expand / create / redesign 라우팅
- `meaningful_design_exists` 기반 경계 판정
- fixed / changeable 디자인 차원
- evidence 및 provenance 요구사항
- 템플릿화 방지와 authoredness 검증
- 제한된 critique / repair
- 결정적 패키징 및 검증

아이디어, 테스트, 구현 이력은 기존 라이선스 범위에서 참고하거나 재사용할 수 있도록 저장소에 남겨 둡니다.
