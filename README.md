## Historical purpose

`design-workflow` was a portable Agent Skill for deciding what should stay fixed, what could change, and whether a visual artifact should be preserved, expanded, created, or explicitly redesigned before an execution tool performed the actual work.

Its main ideas included:

- preserve / expand / create / redesign routing;
- `meaningful_design_exists` as a boundary signal;
- fixed vs. changeable design dimensions;
- evidence and provenance requirements;
- anti-template / authoredness checks;
- bounded critique and repair;
- deterministic packaging and validation.

The repository remains available so those ideas, tests, and implementation history can still be inspected or reused under the existing license.
