# Visual Direction, Reference Rules, and One Repair Pass

> Source and modification notice: This file adapts concepts from Anthropic's
> `frontend-design` Agent Skill, licensed under Apache-2.0. It generalizes them
> across visual media and adds system-level reference analysis and a bounded
> critique. See `THIRD_PARTY_NOTICES.md` in the skill directory.

Apply this shared reference to `create`, explicitly authorized `redesign`, and
`translate` work that requires visual generation or material recomposition.
Evidence priority and the fixed/changeable contract always govern this process.

## Resolve a compact direction first

Before generating, resolve only the decisions that materially affect the result:

- primary message or subject
- audience and viewing context
- first focal point
- hierarchy and reading order
- density and whitespace rhythm
- one organizing composition principle
- functional color roles, with concrete values when the medium supports them,
  rather than unexplained color choices
- display, body, utility, and data typography roles when text is present
- one subject-specific signature element
- one tempting but unnecessary flourish to omit

Keep the direction concise enough to hand directly to the active image or design
tool. Do not expose verbose planning unless it materially helps the user. Derive
the direction from the subject's materials, vocabulary, environment, content,
and use conditions. Spend distinctiveness on one governing idea; keep the rest
disciplined.

Carry supplied content integrity and applicable accessibility constraints—such
as contrast, focus, target size, reading order, and reduced motion—without
turning them into decorative concepts. Do not fabricate copy, claims, metrics,
testimonials, or product capabilities to make a composition feel complete.

For `redesign`, first list the dimensions authorized for replacement and those
that must remain recognizable. Keep content, behavior, legal, accessibility,
platform, compatibility, and migration requirements fixed unless their
replacement is separately authorized. For `translate`, derive the target
direction from the source identity and destination constraints rather than
inventing a new identity.

## Read references as systems

When references are supplied, do not turn visible ingredients into a shopping
list. Classify observed traits as **structural**, **compositional**,
**photographic**, **typographic**, **brand-specific**, or **incidental**. Then
extract the smallest transferable rules that explain the reference's identity:

- where contrast is concentrated
- how spacing establishes rhythm
- what repeats and what intentionally does not
- what is intentionally absent
- the minimum rules that make the reference recognizable
- which traits must not transfer because they conflict with the target content,
  medium, brand evidence, or fixed dimensions

Translate rules to the target's needs instead of copying palette, objects,
effects, poses, or layout literally. Approved project evidence outranks a generic
reference. Record uncertain or conflicting traits instead of resolving them by
surface imitation.

## Reject unsupported defaults

Treat these as discouraged defaults, not absolute bans:

- unexplained purple or blue gradients
- wrapping every element in a rounded card
- default glassmorphism or excessive translucency
- decorative neon, bloom, particles, holograms, circuits, or stock "AI" imagery
- equal three-column icon-card layouts without content justification
- indiscriminate centered alignment
- excessive symmetry or synthetic perfection
- filler decoration added because whitespace feels unfinished
- several unrelated visual concepts competing in one artifact
- effects used instead of hierarchy, composition, or real content

Use one only when the subject, stronger evidence, or explicit user direction
provides a specific reason. State that reason in the compact direction; otherwise
omit the pattern. Empty space, asymmetry, and restraint are valid design choices.

## Execute, then critique and repair exactly once

Generate or compose the draft through the active tool. Before finalization, the
same executing model must perform exactly one critique pass. Check:

- focal-point clarity
- hierarchy against the primary message
- intentional spacing
- coherence around one visual idea
- unsupported generic AI defaults
- superficial reference copying
- the unnecessary flourish named in the direction
- drift outside fixed and changeable dimensions

Apply one repair batch to the highest-impact defects, then stop. Do not critique
the repaired result again or begin a refinement loop. Report a concrete
before-to-after repair; if the artifact cannot be inspected, say that this pass
is pending rather than fabricating it.

## Weak-to-strong examples

**Reference interpretation**

- Weak: “Copy the reference's red circle, condensed type, and thin black grid.”
- Strong: “Transfer its off-axis focal cluster, concentrated headline contrast,
  alternating tight/quiet spacing, and repeated hairline dividers. Do not copy
  the red disc, exact typeface, labels, or empty lower corner; those are
  brand-specific or incidental.”

**Subject-specific composition**

- Weak: “Use a blue-purple gradient hero above three rounded feature cards for
  a botanical specimen archive.”
- Strong: “Organize the interface as a specimen table with an indexed margin,
  a dominant specimen view, and compact provenance annotations. Use cards only
  where records truly need containment; omit the generic gradient.”

**Authorized redesign with fixed information architecture**

- Weak: “Modernize by moving the primary action above the title and merging
  sections.”
- Strong: “Keep the 1080 × 1350 canvas, content order, section boundaries, and
  CTA location fixed. Replace only the authorized type, palette, and graphic
  language; hierarchy must still follow the existing information architecture.”

**Compact handoff plus bounded repair**

- Direction: “Documentary night photograph for neighborhood bicycle-repair
  volunteers; commuters on mobile; focal point is grease-marked hands on a wheel;
  diagonal workbench leads to two supporting figures; close, irregular spacing;
  sodium work light as key and cool street ambience; no text; signature is a row
  of mismatched repaired lights; omit neon motion trails.”
- One critique repair: “The draft's neon trail competed with the hands and made
  the scene look synthetic; remove it and deepen local contrast on the repair.”

## Completion

- The route contract and evidence priority remain intact.
- The compact direction resolves every material field above.
- Only the applicable medium guidance was loaded.
- The result is governed by one visual idea and real content.
- Exactly one critique pass produced one bounded repair batch.
- Unverified tool output or client-dependent quality is reported honestly.
