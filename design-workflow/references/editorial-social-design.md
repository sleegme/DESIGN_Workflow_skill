# Poster, Card-News, and Social Graphic Guidance

Load this file only for posters, card news, or social graphics after loading
`visual-direction.md`.

## Communicate at viewing scale

- Give each frame or page one primary message. Supporting content must not
  compete with it.
- Build hierarchy that survives mobile thumbnails, fast scrolling, or the
  intended reading distance.
- Set a page-to-page system for margins, grid, type roles, image treatment,
  numbering, and repeated anchors; vary it only for a content reason.
- Distinguish the cover's invitation from the interior's explanatory rhythm.
- Edit text length before shrinking type. Control line breaks, widows, labels,
  and contrast deliberately.
- Keep decoration subordinate to communication and preserve required safe areas,
  trim, bleed, and fixed output dimensions.

For sequences, verify that content priority and pacing remain clear without
assuming every viewer saw the previous frame. During the one critique pass,
inspect both a thumbnail/contact sheet and individual full-size frames, then
repair the highest-impact hierarchy or system break once.
