# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-07-16

### Added

- medium-neutral `design-workflow` Agent Skill
- explicit preservation versus redesign boundary
- routing for preserve, expand, create, redesign, critique, brand-check,
  translate, and profile tasks
- progressive reference files and design-profile templates
- realistic routing and trigger evaluation cases
- dependency-free validation scripts
- Apache-2.0 license, source audit, and third-party notices
- GitHub Actions CI
- public release checklist and contributor/security documentation

### Removed from the distributable package

- project-specific names, palettes, layouts, products, and organizational context
- internal routing identifiers not required by the Agent Skills standard
- unverified Canva attribution
