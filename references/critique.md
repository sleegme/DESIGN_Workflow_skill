# Critique and Brand Check

This reference governs `critique` and `brand-check`.

## Analysis only means analysis only

Do not edit, regenerate, or replace the artifact unless the user separately asks
for implementation.

## Evidence-based critique

Evaluate the artifact against:

1. explicit user goal
2. project design contract or brand guide
3. current implementation and interaction behavior
4. approved references
5. medium-specific usability and accessibility requirements

Separate findings into:

- **Mismatch:** conflicts with a known rule or reference.
- **Defect:** clipping, unreadability, broken state, inconsistent token, or
  interaction problem.
- **Weakness:** hierarchy, rhythm, specificity, or communication could improve.
- **Preference:** a subjective alternative, clearly labeled as such.

## Existing-design boundary

Do not call a design "wrong" merely because it does not match a current trend.
Do not recommend a wholesale redesign when local corrections solve the stated
problem.

## Brand audit

Check:

- logo use and protected clear space
- approved colors and contrast
- typography roles and fallback behavior
- shape, icon, illustration, and photography language
- copy register and terminology
- component and layout consistency
- cross-medium consistency
- unauthorized or fabricated claims

## Output

Lead with the highest-impact issue. Cite concrete visual or structural evidence.
For each recommendation, state whether it is a local correction, system-level
change, or optional preference.
