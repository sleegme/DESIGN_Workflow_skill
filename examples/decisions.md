# Routing Examples

| User request | Route | Why |
|---|---|---|
| "Keep this dashboard layout and fix the cramped spacing." | `preserve` | Existing structure is explicitly fixed. |
| "Add a settings screen that matches the current app." | `expand` | New part must inherit the current system. |
| "We have no visual direction yet. Design the landing page." | `create` | No meaningful existing design. |
| "Discard this look and redesign it as an editorial product." | `redesign` | Replacement is explicit. |
| "Why does this feel generic? Do not change it yet." | `critique` | Analysis only. |
| "Check these slides against our brand guide." | `brand-check` | Consistency audit. |
| "Turn this poster into a vertical social story." | `translate` | Same identity, new medium. |
| "Extract a DESIGN.md from the current components and screenshots." | `profile` | Documentation derived from evidence. |
